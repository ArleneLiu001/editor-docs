# 编辑器功能扩展需求
### 引言
公司需要在开源文本编辑器wangEditor的基础上，实现一个富文本编辑器扩展插件，用于在线文档的定制化编辑。

### 功能需求描述
1. 导入文档自动按照格式解析。支持格式为.doc,.docx,.pdf,.txt,.html,.xls,.xlsx图片（是否需要）
2. 解析的文档可以调整查看比例。
3. 可配置页面顶部是否显示编辑按钮区域。
4. 编辑区域包含wangEditor编辑器的基础编辑功能及可配置。
5. 自定义工具栏的插件，按照需要目前增加图片裁剪，插入日期控件。
6. 需要锁定编辑。锁定情况下，只能编辑控件指定下的内容，其他内容不可编辑。
7. 页面底部字数统计。
8. 鼠标悬浮停留位置，可自由添加所需组件：组件包含
文本组件，时间控件，图片控件，表格控件等。
9. 可以对编辑器里面的文档添加锚定点，用于用户对文档特点位置的内容进行编辑，以及知道编辑的是哪些位置信息。
10. 封装整体为文档组件自定义标签插入和填充api。
11. 富文本转文档导出。
12. 选中内容，可AI拓展，优化内容，一键替换内容。
13. 




###  核心功能

#### 1. 富文本编辑器
- **基础编辑功能**：支持标题、段落、列表、表格、代码块等
- **格式化工具**：粗体、斜体、下划线、字体颜色、背景色、字号、行高等
- **媒体插入**：支持图片、视频插入
- **工具栏配置**：可自定义工具栏显示/隐藏
- **只读模式**：支持切换编辑/只读状态

#### 2. 文档导入功能
- **支持格式**：.doc、.docx、.pdf、.txt、.html、.xls、.xlsx
- **导入状态提示**：实时显示导入进度和结果
- **异步处理**：使用FileReader API处理文件读取

#### 3. 图片处理系统
- **图片上传**：支持本地图片选择
- **图片裁剪**：集成ImageCropper组件，支持自定义裁剪
- **Base64转换**：将裁剪后的图片转为Base64格式插入
- **锚点标识**：为每个图片生成唯一ID和标题

#### 4. 自定义控件系统
- **文本控件**：可拖拽插入的可编辑文本框
- **日期控件**：支持日期选择的交互式控件
- **图片控件**：可拖拽插入的图片占位符
- **表格控件**：可拖拽插入的表格，并按需增加行列
- **拖拽功能**：支持从控件面板拖拽到编辑器
- **精确定位**：使用caretPositionFromPoint API实现精确插入位置

#### 5. AI文字优化功能
- **右键菜单**：选中文字后右键显示优化选项
- **优化类型**：
  - 优化文字：提升表达质量
  - 纠正错误：修正语法和拼写
  - 简化表达：使文字更简洁
  - 扩展内容：丰富文字内容
- **异步处理**：带加载状态的API调用
- **文字替换**：使用Range API精确替换选中文字

#### 6. 缩放控制
- **缩放功能**：支持编辑器内容缩放
- **组合式API**：使用useZoom composable管理缩放状态
- **依赖注入**：通过provide/inject在组件间共享缩放状态

#### 7. 日期选择器
- **内联选择器**：点击日期控件显示内联日期选择器
- **模态选择器**：使用Ant Design的日期选择组件
- **dayjs集成**：使用dayjs进行日期格式化
- **动态定位**：自动调整选择器位置避免超出视窗


### 核心技术实现

#### 1. 拖拽插入控件
```javascript
// 使用caretPositionFromPoint获取精确插入位置
const caretPosition = document.caretPositionFromPoint(event.clientX, event.clientY);
// 动态创建DOM元素并插入
const textControl = document.createElement("span");
// 设置自定义属性和样式
textControl.setAttribute("data-w-e-type", "text-control");
```

#### 2. 图片裁剪流程
```javascript
// FileReader读取文件 → 显示裁剪器 → 获取Base64 → 插入编辑器
const reader = new FileReader();
reader.onload = (e) => {
  cropperSrc.value = e.target.result;
  showCropper.value = true;
};
```

#### 3. 右键菜单实现
```javascript
// 监听contextmenu事件，获取选中文字
const selection = window.getSelection();
const text = selection.toString().trim();
// 动态定位菜单位置
contextMenuPosition.value = { x: event.clientX, y: event.clientY };
```

#### 4. 插件注册机制
```javascript
// 注册自定义插件到wangEditor
registerDatePickerPlugin({
  key: "datePickerMenu",
  menuOptions: { /* 配置选项 */ }
});
```

## 特色功能

1. **智能插入定位**：使用浏览器原生API实现精确的拖拽插入位置
2. **实时编辑控件**：文本控件支持原地编辑，无需弹窗
3. **AI文字优化**：集成AI接口提供智能文字优化建议
4. **响应式设计**：适配不同屏幕尺寸的编辑体验
5. **插件化架构**：高度可扩展的插件系统

这个页面展现了现代Web应用的完整技术栈，结合了富文本编辑、文件处理、图像处理、AI集成等多个技术领域，是一个功能完善的文档编辑解决方案。
